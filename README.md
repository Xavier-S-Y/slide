# 土耳其方块 H5

零依赖原生 H5 小游戏，包含普通版和道具版。道具版支持单块移动、单块消除、一行消除和同色消除，并使用 Web Audio 实时合成背景音乐与操作音效。

## 简易玩法设计

### 基础规则

- 棋盘固定为 8 列，滑块长度为 1～4 格，颜色只用于视觉区分。
- 开局生成 3 行滑块，每行滑块总长度小于 8，且不能悬空。
- 每次选择一个已有滑块左右移动；移动结束后，滑块会向下掉落到受到支撑的位置。
- 结算顺序为“下落 → 满行消除 → 再次下落与消除”，直到棋盘稳定后才从底部生成新一行。
- 新行生成时先将原最底行上推，再生成预览中的滑块，并让无支撑滑块自然下落。
- 一行填满 8 格时整行消除；只有稳定后的滑块碰到棋盘顶部才会结束游戏。

### 普通版

只使用基础规则进行游戏，不生成也不能使用道具。

### 道具版

道具版保留全部基础规则，并增加以下内容：

- **单块移动**：选择任意一个滑块，再选择任意不越界、不重叠的合法位置；确认后移动，随后自然下落。
- **单块消除**：选择一个滑块，确认后直接消除。
- **一行消除**：选择棋盘中的一行，确认后消除该行全部滑块。
- **同色消除**：选择一个滑块，确认后消除棋盘中所有同色滑块。

生成新批次时，有 12% 概率让其中一个滑块携带道具；若连续 9 批没有道具，第 10 批必定生成一个。四种道具的生成权重均为 25%。

带道具滑块被任意消除效果清除后，玩家获得对应道具。每种道具最多储存 2 个，超过上限的部分直接溢出。

使用道具时，先点击道具并选择目标，选中目标会高亮并显示相应预览。点击“确定”消耗道具并执行，点击“取消”则退出且不消耗。道具执行后同样依次完成下落和连锁消除，棋盘完全稳定后才生成新一行。

## 运行

在本目录运行内置零依赖服务器：

```powershell
node server.mjs
```

浏览器打开 `http://127.0.0.1:4173`。不要直接双击 `index.html`，浏览器会限制 ES Modules 的本地文件加载。

## 测试

```powershell
node --test tests/*.test.mjs
```
